# Landlord Communication Templates

Plain-English messages you can copy, fill in, and send to your landlord or
property manager.

## How to use

Fill in the blanks for any template, copy the text, and paste it into an
email, text message, or letter. Keep a copy of everything you send (and any
reply) — screenshots or a dedicated folder work fine. These are templates,
not legal advice.

## Maintenance request

When to use: anything broken, leaking, or unsafe — appliances, plumbing,
heat, electricity, locks, pests.

```
Subject: Maintenance request - [unit address]

Dear Landlord or Property Manager,

My name is [your name] and I live at [unit address].

I am writing to request a repair:

- Issue: [what needs fixing]
- Started / urgency: [when it started, how urgent]
- Best way to reach me: [phone or email]

Please let me know when someone can come by. Thank you.

Sincerely,
[your name]
[unit address]
[date]
```

## Rent payment question

When to use: confirming rent was received, asking about late fees, or
requesting a receipt.

```
Subject: Rent question - [month] - [unit address]

Dear Landlord or Property Manager,

My name is [your name] and I live at [unit address].

Regarding rent for [month]:

[your question]

Thank you,
[your name]
[date]
```

## Security deposit return request

When to use: after move-out, to request your security deposit back within
your state's deadline.

```
Subject: Security deposit return request - [unit address]

Dear Landlord or Property Manager,

My name is [your name]. I moved out of [unit address] on [move-out date].

I paid a security deposit of [amount]. Please return it to my forwarding
address:

[forwarding address]

Thank you,
[your name]
[date]
```

## Notice to vacate / lease non-renewal

When to use: telling your landlord you're leaving at the end of your lease.
Check your lease for required notice (often 30 or 60 days).

```
Subject: Notice to vacate - [unit address]

Dear Landlord or Property Manager,

My name is [your name] and I live at [unit address].

Please accept this as my written notice that I will be moving out on
[last day of tenancy].

Please send my security deposit to my forwarding address:

[forwarding address]

Thank you,
[your name]
[date]
```

## Lock / key request

When to use: lost keys, broken locks, or requesting an extra key.

```
Subject: Lock / key request - [unit address]

Dear Landlord or Property Manager,

My name is [your name] and I live at [unit address].

I am requesting: [what you need]
Reason: [why]

Please let me know the cost and how to pick it up.

Thank you,
[your name]
[date]
```

## Noise / neighbor issue

When to use: recurring noise, smoking in shared areas, or other neighbor
issues you want the landlord to address.

```
Subject: Noise / neighbor issue - [unit address]

Dear Landlord or Property Manager,

My name is [your name] and I live at [unit address].

I am writing about the following issue:

[what happened, when, where, what]

I would appreciate: [what you'd like]

Thank you,
[your name]
[date]
```

## Move-out inspection request

When to use: scheduling a walk-through before you move out so you can fix
anything and protect your deposit.

```
Subject: Move-out inspection request - [unit address]

Dear Landlord or Property Manager,

My name is [your name] and I live at [unit address].

I will be moving out on [move-out date]. Please schedule a move-out
inspection.

My preferred time: [preferred inspection time]

Thank you,
[your name]
[date]
```
